# Harshita's Developer Portfolio

A personal portfolio website showcasing my projects, skills, and internship experience — built with HTML, CSS, and JavaScript, with a focus on clean, animated UI.

> **Note:** This repository is a public showcase. The full source code is maintained in a private repository and is not published here. This README documents the project's purpose, features, and tech stack for reference.

## 🔗 Live Site

https://steady-lamington-a08193.netlify.app/

## Overview

This portfolio highlights my work as a final-year IT student, including my key projects, competitive achievements (Flipkart GRID, Google Big Code), and internship experience (IBM SkillsBuild, Kerol Systems). It's designed to give recruiters and visitors a quick, visually engaging overview of my skills and work.

## Features

-  **Animated Skill Cards** — Interactive, animated display of technical skills
-  **Orbital Internship Layout** — Unique circular/orbit-style layout for internship timeline
-  **Achievement Cards** — Dedicated section for competitive programming and hackathon achievements
-  **Fully Responsive** — Optimized for desktop, tablet, and mobile devices
-  **Fast & Modern** — Built with a performant full-stack setup for smooth navigation
